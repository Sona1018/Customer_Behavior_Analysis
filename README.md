# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, understand customer preferences, and evaluate the impact of discounts, shipping methods, and subscription status on revenue.

Using **PostgreSQL, Python, and Power BI**, this project transforms raw customer shopping data into meaningful insights to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze revenue generated by male and female customers.
- Identify customers who use discounts but still spend above the average purchase amount.
- Find the top-rated products based on customer reviews.
- Compare average purchase amounts across shipping methods.
- Analyze spending patterns of subscribers and non-subscribers.
- Identify products with the highest discount usage.
- Segment customers based on their previous purchases.
- Analyze repeat buyers and their subscription behavior.
- Evaluate revenue contribution across different age groups.

## 📊 Dataset Description

The dataset contains **3,900 customer purchase records** with information about customer demographics, purchased products, spending, shipping, discounts, and subscriptions.

Key attributes include:

- Customer ID and age
- Gender
- Purchased item and product category
- Purchase amount
- Customer review rating
- Subscription status
- Shipping type
- Discount and promo code usage
- Previous purchases
- Payment method
- Purchase frequency

## 🔍 SQL Analysis

The project addresses the following business questions using PostgreSQL:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which are the top five products with the highest average review rating?
4. How do average purchase amounts compare between Standard and Express Shipping?
5. Do subscribed customers spend more? How do their average spending and total revenue compare with non-subscribers?
6. Which five products have the highest percentage of purchases with discounts applied?
7. How can customers be segmented into New, Returning, and Loyal groups based on previous purchases?
8. What are the top three most-purchased products within each category?
9. Are customers with more than five previous purchases more likely to subscribe?
10. What is the revenue contribution of each age group?

### SQL Concepts Used

- Aggregate functions: `SUM()`, `AVG()`, `COUNT()`
- Filtering and grouping: `WHERE`, `GROUP BY`, `HAVING`
- Subqueries
- Conditional statements using `CASE`
- Common Table Expressions (CTEs)
- Window functions: `ROW_NUMBER()`
- Sorting and limiting results using `ORDER BY` and `LIMIT`

## ⚙️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Customer-Shopping-Behavior-Analysis.git
```

Replace `YOUR_USERNAME` with your GitHub username and use your actual repository URL.

### 2. Set Up PostgreSQL

1. Install PostgreSQL and pgAdmin.
2. Create a database named `Customer_behavior`.
3. Import the CSV dataset into the `public.customer` table.
4. Open `customer_shopping_behavior_analysis.sql` in pgAdmin.
5. Execute the queries individually to reproduce the analysis.

### 3. Run the Python Notebook

1. Open Google Colab or Jupyter Notebook.
2. Upload or open the `.ipynb` notebook.
3. Upload the dataset if required.
4. Run the notebook cells sequentially.

### 4. Open the Power BI Dashboard

1. Open `Customer_Behavior_Dashboard.pbix` in Power BI Desktop.
2. Configure the PostgreSQL connection if prompted.
3. Refresh the data if required.
4. Explore the dashboard and its visualizations.
